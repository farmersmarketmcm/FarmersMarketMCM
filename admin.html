📁 Cara Upload Data Produk agar Bot Bisa Menjawab Lokasi Lorong Buat file bernama products.json dan simpan di folder yang sama dengan index.html (web customer).
📋 Format products.json 
[
  {
    "nama": "Wortel Organik",
    "kategori": "Sayuran",
    "lorong": "Lorong A-3",
    "alias": ["carrot","wortel"],
    "keterangan": "Tersedia per kg & per ikat"
  },
  {
    "nama": "Apel Fuji",
    "kategori": "Buah",
    "lorong": "Lorong B-1",
    "alias": ["apel","apple fuji"],
    "keterangan": "Impor dari China, harga per buah"
  }
]
  • nama – nama resmi produk
  • kategori – Sayuran / Buah / Daging / dll
  • lorong – lokasi di pasar, mis. Lorong A-3, Stand 12
  • alias – kata kunci alternatif (opsional)
  • keterangan – info tambahan (opsional)
🚀 Langkah Deploy ke Hosting
  1. Siapkan 3 file: index.html (customer), admin.html (admin), products.json
  2. Upload ketiganya ke root hosting kamu (cPanel → File Manager → public_html)
  3. Akses https://domain-kamu.com/ untuk customer
  4. Akses https://domain-kamu.com/admin.html untuk admin
  5. Update products.json kapan saja melalui tab Data Produk lalu klik Export JSON → upload ke hosting
  6. Atau gunakan Netlify Drop: drag-drop folder ke app.netlify.com/drop – gratis!
⚠️ Catatan Penting Chat history admin↔customer menggunakan localStorage (tersimpan di browser lokal). Untuk produksi skala besar, gunakan backend (Node.js / Firebase / Supabase) agar data tersinkron antar perangkat. Hubungi developer untuk integrasi backend.
