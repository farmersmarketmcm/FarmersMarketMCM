🔥 Firebase Aktif – Chat History Tersimpan Permanen Semua percakapan customer kini tersimpan di Firebase Firestore milik kamu. Data aman, tidak hilang walau browser di-clear, bisa diakses dari HP/komputer manapun, dan tersimpan hingga berbulan-bulan.
📁 Cara Update Data Produk
  1. Tambah / edit produk di tab Data Produk
  2. Klik ⬇ Export JSON → download file products.json
  3. Upload file tersebut ke repo GitHub (ganti yang lama)
  4. Tunggu 1-2 menit → bot langsung bisa menjawab
⚠️ Atur Firestore Security Rules Di Firebase Console → Firestore → Rules, ganti dengan rules ini agar lebih aman:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /chats/{doc} { allow read: if false; allow write: if true; } match /admin_replies/{doc} { allow read, write: if true; } match /stats/{doc} { allow read: if false; allow write: if true; } } }
